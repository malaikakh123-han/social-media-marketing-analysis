# Social Media Marketing Analysis

## Overview

This project analyzes a social media marketing dataset using Microsoft Excel to identify patterns and trends in campaign performance.

The analysis focuses on marketing channels, customer segments, conversion rates, acquisition costs, ROI, demographics, and overall campaign performance.

## Tools Used

- Microsoft Excel
- PivotTables
- Excel formulas
- Data cleaning
- Data analysis
- Data visualization
- Dashboarding

## Dataset

The dataset contains 15,000+ social media marketing records with information related to:

- Campaigns
- Marketing channels
- Customer segments
- Demographics
- Geographic information
- Conversion rates
- Acquisition costs
- ROI
- Clicks and engagement
- Campaign performance

## Analysis

The project explores:

- Campaign performance across different channels
- ROI and acquisition costs
- Conversion rates
- Customer segment performance
- Demographic trends
- Geographic performance
- Marketing campaign trends
